About MoneyFlow

Managing daily spending can be difficult when transactions are recorded in different places. MoneyFlow aims to provide an organised view of personal finances and help users make informed spending and saving decisions.

🎯

Project aim

Provide a simple way to record, organise and review personal income and expenses.

👥

Multiple users

The desktop project includes account registration and login so users can maintain separate records.

📊

Financial overview

Understand money received, money spent and balance calculated from recorded transactions.

Main features

Features present in the supplied desktop project include:

🔐

Registration and login

User registration, login and password hashing.

💰

Income tracking

Record income with amount, date and description.

🧾

Expense tracking

Add, edit, delete, search and categorise expenses.

📅

Transaction history

Review financial records and expense totals.

🏦

Bank account records

Manage account details supported by the desktop project.

🔁

AutoPay records

Maintain recurring payment information and reminders.

🐷

Savings goals

Set targets and track savings progress.

🛡️

Admin module

Admin login and user/expense management features.

How to use the desktop application

Install the dependencies and start the Electron desktop application on your computer.

1
Install Node.js
Install a supported Node.js LTS version.
2
Install project dependencies
Open a terminal in the extracted project folder and run npm install.
3
Start MoneyFlow
Run npm start to launch the Electron desktop app.

Technology used

The supplied application is an Electron desktop application built with web technologies and a local data store.

HTMLCSSJavaScriptElectronNode.jsJSON local database

Important: GitHub Pages versus desktop app

This homepage is a static project-information website. GitHub Pages cannot run Electron's main process, preload scripts, Node.js APIs or the desktop application's local JSON database. The actual app source is included in this repository for download and local use.

Financial safety: This GitHub Pages website does not provide live bank/UPI synchronisation, money transfers or real bank debits. Those require secure backend services and authorised financial/payment integrations. Never enter bank passwords, UPI PINs or OTPs on this static page.

Run the app locally

Download or clone this repository, open the project folder in a terminal, run npm install, then run npm start.
